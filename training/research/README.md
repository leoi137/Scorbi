# Training record

Append-only. One file per entry, numbered in the order written. An entry is never edited after
its run; a correction is a new entry that names the one it corrects.

- **Before a run:** what changes, the one variable, the prediction, and what result would count as wrong.
- **After a run:** the final-checkpoint numbers, the spread, the falls, the checkpoint's hash, and whether the prediction held.
- **Decisions** and **anomalies** get their own short entries, with the evidence.

Nothing here is a product claim. Every number is from simulation of a robot that has not been built.
